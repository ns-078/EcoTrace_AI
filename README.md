# 🌱 EcoTrace AI – Intelligent Greenwashing Detection & ESG Analysis

## 📌 About the Project

EcoTrace AI is an AI-powered sustainability analysis system designed to analyze corporate environmental claims and ESG (Environmental, Social, and Governance) data. It uses Natural Language Processing (NLP) techniques to extract and analyze sustainability-related information and help users understand potential environmental risks and misleading green claims.

The project aims to promote transparency, improve sustainability awareness, and support informed decision-making through data-driven analysis.

## 🎯 Objectives

- Analyze corporate sustainability claims using NLP techniques.
- Process and examine ESG-related datasets.
- Identify potential inconsistencies in environmental claims.
- Present sustainability information through an interactive dashboard.
- Support better understanding of corporate ESG performance.

## ✨ Key Features

- **ESG Data Analysis:** Analyze environmental, social, and governance-related data.
- **NLP-Based Claim Analysis:** Extract and process sustainability-related statements.
- **Greenwashing Analysis:** Support the identification of potentially misleading environmental claims.
- **Interactive Dashboard:** Display analysis results in a user-friendly interface.
- **Data-Driven Insights:** Help users understand corporate sustainability information.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Artificial Intelligence:** Machine Learning and Natural Language Processing
- **Data Processing:** Pandas, NumPy
- **NLP:** Text preprocessing and claim analysis
- **Visualization:** Streamlit and data visualization libraries
- **Dataset:** ESG Risk Ratings and sustainability-related datasets

## ⚙️ System Workflow

1. Load ESG and sustainability-related datasets.
2. Preprocess and clean the collected data.
3. Extract and analyze relevant sustainability claims using NLP.
4. Analyze ESG-related information to understand potential risks.
5. Display the processed results through an interactive dashboard.

## 🚀 Installation and Setup

### Prerequisites

- Python 3.10 or later
- Git
- pip package manager

### Step 1: Clone the Repository

```bash
git clone https://github.com/ns-078/EcoTrace_AI.git
```

### Step 2: Navigate to the Project Directory

```bash
cd EcoTrace_AI
```

### Step 3: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

### Step 4: Install Dependencies

If a `requirements.txt` file is available, run:

```bash
pip install -r requirements.txt
```

### Step 5: Run the Application

If the project entry point is `app.py`, run:

```bash
streamlit run app.py
```

Use the actual application entry-point filename if it differs.
